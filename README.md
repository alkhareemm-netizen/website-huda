# Huda Photography Website

Static website for Huda Photography. Deployed on Cloudflare Pages.

## Structure
- `index.html` - Home page
- `about.html` - About page
- `contact.html` - Contact page
- `service.html` - Services page
- `portofolio.html` - Portfolio page
- `style.css` - Stylesheet
- `image/` - Images and media assets
- `hero-video.mp4` - Hero background video

## Deployment
This is a static site. Deploy to Cloudflare Pages with the root directory
as the build output, no build command required.
